`worktree://<id>`: isolation manager for agent `<id>`'s retained workspace. Write `/integrate` (verbatim) with `write` to capture its latest changes and merge them into the parent repository recorded at spawn; only the same parent session that spawned it may signal. A running agent is refused, conflicts leave the workspace and artifacts intact, and a repeat signal after success is a no-op. Reading this URL only describes the handoff; use `history://<id>` for status and `agent://<id>` for output.
